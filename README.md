# Logoped AI 🗣️🧠

Инновационный AI-логопед для детей и взрослых. Бот анализирует голосовые сообщения, распознает дефекты речи, оценивает произношение и предлагает индивидуальные артикуляционные упражнения для улучшения дикции.

## 🚀 Функционал
* **Анализ произношения (Speech-to-Text)**: Точное распознавание речи и выявление проблемных звуков (например, "Р", "Л", шипящие).
* **Голосовая обратная связь**: Озвучивание правильного произношения (Text-to-Speech).
* **Индивидуальный план тренировок**: Подбор скороговорок и логопедических игр на основе выявленных ошибок.
* **Трекинг прогресса**: Сохранение истории занятий и визуализация улучшений.

## 🛠 Технологии
* **Язык**: Python 3.10+
* **Распознавание речи (ASR)**: `Whisper API` (OpenAI) или локальная модель `Vosk`
* **Синтез речи (TTS)**: `ElevenLabs` или `Google TTS`
* **Бэкенд / ИИ**: `FastAPI` + `LangChain` для логики рекомендаций
* **Интерфейс**: Telegram Bot API
